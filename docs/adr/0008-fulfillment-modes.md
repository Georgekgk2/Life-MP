# ADR 0008 - Режими фулфілменту та власність залишків

- **Дата:** 2026-07-27
- **Власник ADR:** технічний власник Life-MP
- **Статус:** Accepted (Прийнято)

---

## Контекст

На початковому етапі (MVP) платформа «ЛАЙФ» розгортається без власного централізованого складу. Виробники відправляють замовлення безпосередньо покупцям (Direct Marketplace). У майбутньому планується створення власного складу для товарів тривалого зберігання та закупівля товарів лотами для надання клубних знижок.

Архітектура каталогу та замовлень повинна підтримувати гнучкі режими доставки без перезапису доменної моделі при переході до складської системи.

---

## Рішення

1. **Модель `fulfillment_mode` на рівні позиції каталогу/вендора**:
   - `vendor_direct`: Товар зберігається у виробника та відправляється безпосередньо покупцю Новою Поштою.
   - `platform_warehouse`: Товар зберігається на власному складі «ЛАЙФ» та відвантажується платформою.
   - `hybrid`: Вендор відправляє частину товарів напряму, а частину популярних позицій — зі складу платформи.

2. **Модель власності товару (`seller_model`)**:
   - `vendor_is_seller`: Виробник є юридичним продавцем товару (Seller of Record).
   - `platform_is_seller`: Платформа викуповує лот товару та виступає продавцем від свого імені (Merchant of Record).
   - `lead_only`: Послуги та турпродукти висвітлюються лише для збору заявок без оформлення замовлення.

3. **Реалізаційні межі для MVP**:
   - На старті дозволено лише режим `vendor_direct` та `vendor_is_seller` у тестовому синтетичному режимі.
   - Будь-який розрахунок мульти-складської логістики чи оптимізація маршрутів фулфілменту відкладаються до юридичного прийняття рішення про відкриття складу.

---

## Наслідки

- Доменна модель товару та вендора містить чіткі явні переліки `fulfillment_mode` та `seller_model`.
- Доставка Новою Поштою підтримує мульти-вендорне розщеплення відправлень для прямих відвантажень.
