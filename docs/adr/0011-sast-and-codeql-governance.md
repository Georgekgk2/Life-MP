# ADR 0011 — Управління SAST, CodeQL та безкомпромісними перевірками безпеки (Fail-Closed Security Scans)

- **Дата:** 2026-08-19
- **Власник ADR:** технічний та security-власник Life-MP
- **Статус:** Accepted (Прийнято)

## Контекст

1. **Обмеження GitHub Advanced Security (GHAS):**
   Приватні репозиторії на базових та Pro-планах GitHub не мають доступу до REST API завантаження результатів Code Scanning (`api.github.com/repos/.../code-scanning/sarifs`). Спроби завантаження призводять до аварійного завершення екшену з кодом помилки `403 / Code scanning is not enabled for this repository`.
2. **Вимоги до якості SAST:**
   Кодова база потребує автоматизованого статичного аналізу безпеки (CodeQL AST analysis) без перетворення інфраструктурних обмежень GitHub на хронічно червоні статуси пайплайнів.
3. **Принцип Fail-Closed:**
   Попередні конфігурації містили замовчування помилок (`|| true`, `exit-code: "0"`), що суперечить політиці Skeptic Mode.

## Рішення

1. **Автономне виконання CodeQL з генерацією артефактів:**
   - Налаштувати `github/codeql-action/analyze@v3` із параметром `upload: "never"`.
   - Зберігати згенерований SARIF-звіт як артефакт workflow (`actions/upload-artifact@v4`) з терміном зберігання 14 днів для можливості аудиту та локального аналізу.
   - Це забезпечує повний семантичний аналіз коду TypeScript/JavaScript без падіння на викликах відсутнього GHAS API.
2. **Безкомпромісний аудит залежностей (Fail-Closed):**
   - Видалити всі обхідні конструкції `|| true` з аудиту залежностей.
   - Встановити поріг блокування: `pnpm audit --prod --audit-level=high` (будь-яка вразливість рівня High або Critical зупиняє пайплайн).
3. **Суворий скан образів Trivy:**
   - Зафіксувати екшен `aquasecurity/trivy-action` за перевіреним immutable commit SHA (`d2a0b60797ff03db6132bd4e2b293f9b37081297`) для детермінованого захисту від supply-chain атак через плаваючі теги.
   - Встановити `exit-code: "1"` на виявлення вразливостей категорій HIGH та CRITICAL.
   - Перевіряти історію шарів контейнера на наявність секретів з аварійним зупиненням (`exit 1`) при виявленні артефактів.

## Наслідки

- **Позитивні:** Пайплайн CodeQL стає детерміновано зеленим, якщо код безпечний; усі безпекові перевірки працюють у режимі Fail-Closed.
- **Обмеження:** Результати CodeQL доступні у вигляді скачуваних SARIF-артефактів, а не нативної вкладки "Security Dashboard" у GitHub до моменту активації GHAS.
