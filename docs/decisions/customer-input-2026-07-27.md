# Вхідні рішення та уточнення замовника (2026-07-27)

## Статус
Фіксує нормалізовані рішення на основі прямих відповідей замовника щодо фази розробки, категорій товарів, сертифікації, фулфілменту та клубної програми.

---

## 1. Позиціонування та мета етапу

- **Промоверсія платформи:** Проєкт «ЛАЙФ» на даному етапі є промоверсією платформи з дослідженням та моніторингом попиту серед різних соціальних груп.
- **Ціль:** Проведення контрольованого пілоту для вимірювання інтересу, конверсії та реального попиту за категоріями перед повномасштабним комерційним запуском.
- **Дія в коді:** Транзакційні онлайн-платежі, кошик і автоматичні виплати залишаються вимкненими.

---

## 2. Відбір вендорів, якість та сертифікація

- **Критерії відбору:** На платформу допускаються лише виробники, з якими узгоджено співпрацю та які пройшли внутрішній відбір за критеріями: **Якість, Корисність, Екологічність**.
- **Обов'язкова сертифікація:** До вистави допускаються лише сертифіковані товари/виробники. Для виробників у процесі оформлення документів діє статус ручної модерації.
- **Збір документів:** Відбір вимагає збору юридичних реквізитів (ЄДРПОУ/РНОКПП), копій сертифікатів та документів про реєстрацію оператора ринку.
- **Публічні позначки довіри:**
  1. `Перевірений виробник ЛАЙФ` — пройдено ручну перевірку реквізитів платфомою.
  2. `Сертифікований товар` — завантажено та підтверджено сертифікат/декларацію.
  3. `Органічний продукт` — підтверджено наявність в офіційному ДП «Державний реєстр операторів органічного виробництва».

---

## 3. Модель фулфілменту (Доставка та склад)

- **Старт без власного складу (MVP):** Пряме відправлення покупцю від виробника (`vendor_direct` fulfillment via Nova Poshta).
- **Майбутня гібридна модель:** При появі власного складу товари тривалого зберігання зможуть відвантажуватися зі складу платформи (`platform_warehouse` / `hybrid`).
- **Викуп лотами:** Викуп партій товарів платформою для формування клубних знижок відкладено до стадії складського фулфілменту.

---

## 4. Категорії товарів та черговість запуску

| Категорія | Пріоритет | Статус запуску у каталозі |
|---|---|---|
| Сухі харчові продукти, батончики, смаколики | **P0** | Дозволено для синтетичного каталогу та пілоту |
| Біжутерія | **P0** | Дозволено для синтетичного каталогу та пілоту |
| Тренажери, фітнес-аксесуари (побутові) | **P0** | Дозволено без медичних claim-ів |
| Ароматерапія | **P0** | Дозволено косметичні/побутові позиції |
| Послуги, туроператори | **P1** | Лише у формі заявок (lead generation), без онлайн-бронювання |
| М'ясо, зелень, свіжі овочі | **P2** | Заблоковано для першого checkout (потрібні температурні SLA) |
| Медичне/ортопедичне обладнання | **P2** | Заблоковано для першого checkout (потрібна перевірка ліцензій) |
| Психологічні послуги | **P2** | Заблоковано для першого checkout (потрібна дисклеймер-система) |

## 5. Клубна картка та програма лояльності (Заблоковано)

- **Концепція:** Клубний рівень (10 000 грн / 50 000 грн) визначає рівень накопиченого обороту покупця для отримання знижок.
- **Сувора заборона на старті:**
  - Заборонено реалізовувати платні вступні внески, депозитні рахунки, баланси «на гаманці», фінансовий кешбек, інвестиційні або реферальні виплати.
  - Клубна картка не є фінансовим або інвестиційним інструментом.
