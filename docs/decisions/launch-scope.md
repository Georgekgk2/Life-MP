# Межі запуску та безпечні відкладення (Launch Scope & Boundaries)

**Станом на поточну версію.** Цей документ встановлює межі між реалізованими автономними модулями (розробка/Sandbox) та заблокованим бойовим запуском (Live Production). Детальний доказ, власник, наступна дія та критерій приймання кожного питання містяться в [реєстрі відкритих рішень](open-questions.md) та [пакеті рішень Phase 4B](phase4b-decision-pack.md).

---

## 1. Реалізовані межі в кодовій базі (Sandbox & Development Ready)

| Модуль / Функціонал        | Що реалізовано в коді                                                 | Призначення та обмеження                                                                                                  |
| -------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Мультивендорний кошик**  | `CartContext`, `CartDrawer`, `AddToCartButton`                        | Дозволяє додавати товари різних майстерень та бачити розрахунок за кожною з них. Працює локально через `localStorage`.    |
| **Оформлення замовлення**  | Форма `/checkout`, валідація контактів, доставка Новою Поштою, Escrow | Тестове оформлення замовлення без залучення реальних банківських карт.                                                    |
| **Розщеплення замовлень**  | `SandboxOrderEngine`, `ParentOrder`, `VendorChildOrder`               | Автоматичний розподіл єдиного замовлення на окремі посилки для кожної майстерні з розрахунком 10% комісії та 90% виплати. |
| **Escrow-холдинг**         | `EscrowHoldRecord` (`held` ➔ `captured`)                              | Симуляція двостадійного холдування коштів покупця до моменту вручення посилки.                                            |
| **Логістика та виплати**   | Генерація ТТН, трекінг-симулятор, `SettlementBatch`                   | Автоматичне формування виплати на IBAN майстра при отриманні `Статусу 9: Вручено` Нової Пошти.                            |
| **Progressive Web App**    | `app/manifest.ts`, `public/sw.js`, `InstallPwaPrompt`                 | Встановлення додатка на смартфон, Stale-While-Revalidate кешування, офлайн-підтримка.                                     |
| **Пошуковий рушій**        | `PostgresFtsSearchProvider` + морфологія + Meilisearch                | Швидкий пошук (Cmd+K), автокомпліт, крафтові синоніми та виправлення помилок.                                             |
| **Модерація та онбординг** | `/join-as-artisan`, `/vendor/products/new`, `/moderation`             | Повна дворівнева модерація заявок майстерень та товарних позицій.                                                         |

## 2. Фундаментальні блокери для бойового запуску (Live Production Blockers)

Поки кожен пункт нижче не отримає письмового затвердження стейкхолдерів у [реєстрі погоджень Phase 4B](phase4b-approval-register.md), перехід до бойового еквайрингу та розгортання в production **суворо заблокований**:

| Код               | Питання / Блокер                                      | Необхідний артефакт для розблокування                       |
| ----------------- | ----------------------------------------------------- | ----------------------------------------------------------- |
| **COM-1 (LGL-1)** | Юридична модель продавця (Агентська модель)           | Підписаний договір приєднання та публічна оферта покупця.   |
| **COM-2 (FIN-1)** | Платіжний еквайринг (LiqPay / WayForPay / RozetkaPay) | Договір з еквайром на спліт-виплати та бойові API-ключі.    |
| **COM-3 (FSC-1)** | Фіскалізація через ПРРО (Checkbox / Вчасно.Каса)      | Налаштування каси та токенів ПРРО для фіскалізації комісії. |
| **LOG-1**         | Корпоративний акаунт Нової Пошти                      | Договір та бойовий API-ключ для генерації реальних ЕН.      |

## 3. Вимкнені можливості (Out of MVP Scope)

1. **Бойовий прийом платежів та реальні банківські списування:** заблоковано політикою Phase P0 Containment.
2. **Платні послуги, бронювання та ticketing:** відкладено на після-MVP.
3. **Affiliate-програма та реферальні виплати:** повністю вимкнено до появи окремого юридичного висновку.
4. **Міжнародна доставка:** старт обмежено територією України.
