# Приватний backport `braces` для Life-MP

Цей workspace-пакет містить upstream `braces@3.0.3` (MIT; ліцензія — у `LICENSE`) із межею вкладеності парсера для [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).

Парсер приймає не більше 64 вкладених AST-блоків. Якщо межу перевищено, весь шаблон трактується як звичайний текст: API `compile` та `expand` повертають початковий шаблон, не обходячи рекурсивно AST, контрольований зловмисником.

`3.0.4+life.1` — внутрішній ідентифікатор збірки, а не реліз upstream `braces`. Залишайте цей fork лише доки upstream не випустить еквівалентне виправлення, а аудит залежностей і сканування образів не підтвердять результат. Пакет приватний; не публікуйте його як реліз upstream.
